# U2: User manual

Milestone M2, status 🔨. Open (one line, as in the TODO table): Written from code + emulator; board pictures open

## Description

A user manual in `docs/manual/` (Alex, 2026-10-24): every menu, every function and the apps of the release, with
screenshots; mirrored to the GitHub wiki next to Architecture and Capabilities. It documents release `b151154b`
(app `234a0abb`) and is updated with every release.

Sources, in this order: the app code at the pinned commit, the gateware (what a setting does on our bitstream), the
ue2emu emulator running the release's `.ue2` with our capability word (`--caps 25E40202 --board c64u`) for the
screenshots. Specs and comments only as pointers.
