# U1: trex_crt: Erase Cartridge in the F5 menu, and the writer stages the CRT on our core

Milestone M2, status 📅. Open (one line, as in the TODO table): Scope decided, not built

## Description

Two changes to the trex_crt app (`apps/trex_crt` in the app fork, trx64/main), as one package (Alex, 2026-10-22).

**1. Erase Cartridge.** A new task entry in the F5 menu, category "C64 Machine", beside Dump Cartridge, Cart Inspector
and Flash Cartridge (`manifest.json` `tasks`, action `erase`, handled in `main.c`). Not in the file context menu: erasing
needs no file. The erase routines exist and are used only inside the write today (`cart_writer.c`: `flash_chip_erase`,
`ef3_erase_slot`, `ef3_erase_cart`, `gmod2_chip_erase`); the new flow around them:

- Detect the cartridge in the port as the writer does; every type the writer flashes (EasyFlash 1, EasyFlash 3,
  MegaByter, GMod2, C64MegaCart). No cartridge or a type the writer cannot flash: one popup with the reason, nothing erased.
- Ask before erasing, with the detected type and size.
- EasyFlash 3: ask whether to erase one slot or all 8 slots.
- GMod2: ask whether the EEPROM (the save games) is erased too; default NO.
- Blank check afterwards: every byte erased reads $FF, otherwise an error with the first failing bank.
- Host tests in `apps/trex_crt/host` for each type and each answer, register traffic as for the write.

**2. The writer stages the CRT on our core.** Today the writer reads the whole CRT into RAM only on Gideon's core; on our
core it streams every pass (summary, validation, write, verify) from the file (app e61e2ede, 2026-10-04: a 1 MB
EasyFlash needed 2 MB contiguous with the doubling `realloc`, the heap had no such block). A USB stick that drops off
during a long write (EasyFlash 3 keeps the bus busy for about half a minute; seen on Gideon's core) then breaks the write
half way. Fix: stage the CRT as the dumper does (`cart_dumper.c` `crt_sink_t`): 64 KB heap blocks, a file on the RAM disk
`/Temp` when the heap has not enough, the stream only when both fail; then every pass reads from the stage.
