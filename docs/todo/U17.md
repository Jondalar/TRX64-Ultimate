# U17: The picture's scale: Integer, Fit, Fill

Status 📋. Open (one line, as in the TODO table): Split off from U16 (D3); nothing built

## Description

[U16](../specs/U16-hdmi-modes.md) D3 scales the VIC window in every HDMI mode by the largest factor that keeps
today's proportions ("Fit"). MultiCore's cores have a "Scale" setting with three values (MultiCore T107 D8, Alex
2026-10-29): **Integer** (the largest whole factor, sharp, black border), **Fit** (the largest that keeps the
aspect), **Fill** (the whole active area, stretched). MultiCore's `host/pix_layer.v` (T164 WP5) has the phase
accumulators for it. For this design it is the scaler's step per axis, chosen by the application.
