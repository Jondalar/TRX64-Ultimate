# Provenance of the gateware

Every FPGA building block that the TRX64 Ultimate builds read, where it comes from and
under which licence. Scope is what the build scripts hand to Vivado
(`designs/*/build.tcl`, `tools/vivado_lib.tcl`, `tools/gideon_sources.sh`,
`tools/vendor_gideon.sh`), not everything that lies in the tree. Licences of the repository:
`LICENSE` and `LICENSING.md`.

Designs: **c64** = `designs/c64_basic`, **ddr2** = `designs/ddr2_test`,
**hdmi** = `designs/hdmi_test`.

"Read, pruned" means the build reads the files but the block is not instantiated with
the parameters we use, so it does not end up in the bitstream.

Every licence below is taken from a licence file or a file header named in the row.
"Unknown" means: no licence file, no header with a licence, and no record in this
repository.

## Ultimate half: `cores/gideon`

Parts of Gideon Zweijtzer's 1541ultimate (`fpga/`), taken by `tools/vendor_gideon.sh`
from the submodule `software/ultimate-app` (Gitea `TREX/1541ultimate`, branch
`trx64/main` per `.gitmodules`; upstream https://github.com/GideonZ/1541ultimate).
`cores/gideon` is generated and not in git; `cores/gideon/VENDOR.md` records the commit
it was made from: the submodule commit pinned on main, **234a0abbd3c59a3002c8202e7f3c749d98811fba**.
Licence of the repository: GNU GPL version 3, copied as `cores/gideon/LICENSE.txt`.
Most files name Gideon Zweijtzer / Gideon's Logic Architectures / Gideon's Logic B.V. in
the header (2004-2026); many have no header at all; only
`fpga/1541/vhdl_source/via6522.vhd` states a licence itself ("License: GPL 3.0").

`tools/vendor_gideon.sh` refuses any file containing "without written permission".
Clean-room rule: Gideon's UltiSID (`fpga/sid6581`), Copper (`fpga/io/copper`) and
`lp_filter` (`io/audio/lp_filter*`) are not vendored, not used and must not be opened.
This document was written without opening them.

(or its built-in defaults) through its ROM apertures, as on Gideon's core
(`ultimate_sys.vhd`). The 1541's ROM is in DDR2, written by the app (`drive_mem.vhd`).

ddr2_test and hdmi_test contain only our own code and AMD/Xilinx IP.

AMD/Xilinx IP in a bitstream: the repository holds only configuration (`build.tcl`) and computed
values (`mode_ctl.v`); the GT wizard is generated by Vivado at build time, the primitives come from
the unisim library. The corresponding source of a bitstream is the sources plus the build scripts;
Vivado (the free edition covers the XC7A50T) regenerates the IP from them. The primitives and IP
generators fall under the GPL-3 section 1 "System Library" exception, and AMD's terms allow
bitstreams with its IP to be distributed for AMD devices. A bitstream passed on says: "AMD IP is
generated from the configuration at build time; Vivado is needed."
